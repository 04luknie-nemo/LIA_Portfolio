# LIA Connect

Kopplar ihop studenter (systemutvecklare .NET) med företag för LIA-platser.

## Struktur

- mobile/  Expo-app (React Native, expo-router)
- api/LiaConnect.Api/  ASP.NET Core Web API (.NET 9)

## Kom igång

Mobil:

    cd mobile
    npm install
    npx expo start

API:

    cd api/LiaConnect.Api
    dotnet run
